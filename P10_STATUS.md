## Новый функционал

### P10A — реальные геометрические поверхности OpenCascade

- p10_cad_feature_worker.py читает не текстовые координаты STEP, а настоящую BREP-модель OpenCascade.
- Для цилиндров измеряет радиус и осевое направление/местоположение. Для плоскостей получает нормаль и угол между геометрической плоскостью и выбранной декартовой осью; вычисление: asin(abs(n dot axis)).
- Повторяющиеся аналитические грани с одинаковой геометрической параметризацией объединяются в группы; сохраняются исходные индексы граней и число в группе. Для плоскостей одинаковые ориентации могут соответствовать разным физическим плоскостям, поэтому автоматическая привязка выноски чертежа запрещена.
- Идентификатор геометрического кандидата формируется из SHA-256 STEP и параметров поверхности. У старого/изменённого файла ID не совпадает.
- feature_verification.py проверяет действительную связку PDF + STEP + BOM из P7, исходные SHA-256, единицы измерения, тип обозначения и поверхности. Не смешивает радиус с углом; для радиуса требуется цилиндрическая грань, для угла — плоскость и ось.
- В интерфейсе можно выбрать надпись из PDF, аналитическую поверхность из STEP и ось для угла. Все результаты помечаются как пользовательская гипотеза о соответствии надписи грани, а не конструкционная приёмка.

Реальные подтверждённые **числовые измерения геометрии**:
- focuser_drawtube: PDF R41.5, OpenCascade радиус цилиндрической поверхности 41.5 мм; разница 0 мм. Геометрическая группа содержит 3 CAD-грани. Обозначение на PDF находится на странице 1 с относительными координатами; установление соответствия именно выбранной поверхности НЕ завершено.
- lower_square_tube: PDF 67.38°; угол наклонной плоской группы к оси X из OpenCascade = 67.38015°, абсолютная разница 0.00015°. Группа из 4 граней с одинаковым направлением нормали. Выбор оси Y даёт числовое расхождение.
- Три другие проверенные цепочки P7 не выдумываются для BCN3D или Passport; там нет подтверждённой связки всех трёх типов.

Что пока НЕ реализовано: установление к какой конкретно грани ведёт размерная стрелка чертежа, проверка отверстий и сопряжений по координатам, нормативные допуски/посадки, допуски формы и расположения (GD&T), анализ CAD-конфигураций, сравнение всей геометрии и итоговая приёмка.

### P10B — контракт корпоративного источника редакций

- revision_gateway.py предоставляет **read-only** модель входящего снимка редакции PLM либо 1С ERP. Снимок JSON с явно заданными полями: schema, source_system, issuer, issued_at, expires_at, part_key, revision, drawing_sha256, cad_sha256, release_event_id, status.
- Снимок проверяется локально по Ed25519-подписи против публичного ключа из административно установленного реестра. Проверяются поля, срок жизни не более 14 дней, временные метки, источник, идентификатор детали и SHA-256 действительных оригиналов.
- Источник на стенде по умолчанию **НЕ подключён**. Возвращается NO_AUTHORITATIVE_CONNECTOR.
- Администратор может использовать переменные P10_PLM_SNAPSHOT_FILE (путь к локальному снимку) и P10_PLM_PUBLIC_KEYS_JSON (словарь key_id → raw Ed25519 public key в hex) для *испытания криптографической целостности*. Указанный публичный ключ не является автоматически подтверждением корпоративных полномочий.
- Даже корректно подписанный снимок с заявлением RELEASED возвращает manufacturing_authorization=false, revision_status=NOT_VERIFIED_IN_DRAWING_AND_AUTHORITATIVE_REPOSITORY и legal_e_signature=NOT_EVALUATED.
- Файл не изменяется, URL не открываются, полномочия не подделываются, реальные PLM/1С и подпись по российскому квалифицированному ЭП не подключены.
- Для действительной интеграции необходимо выбрать PLM/1С, их SDK/REST/OData, реестр действующих редакций, отзывов, ключи организации, юридическую модель ЭП, сервисную read-only учётку, журнал источников и корпоративные ACL. Нельзя утверждать, что P10 уже выполняет это автоматически.

## Безопасность и ограничения

Доступ ко всем P10 API только по учебной роли с инженерным scope, на localhost; права и сессия повторно сверяются перед отдачей результата после дорогостоящего CAD-анализа. Выдача исходного PDF/STEP перепроверяет SHA-256. Используются ограничения на объём STEP и число граней, краткоживущий subprocess с таймаутом. Полноценной OS-песочницы PDF/STEP нет. Демонстрационные роли без SSO; не загружать закрытую документацию.

API:
- GET /api/engineering/p10/features?q=focuser_drawtube
- GET /api/engineering/p10/compare?q=focuser_drawtube&annotation=...&feature=...&axis=x&window=0.02
- GET /api/engineering/p10/revisions?q=focuser_drawtube
