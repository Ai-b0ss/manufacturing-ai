## Сделано

1. Исходные PDF проверяются по SHA-256, и из реального текстового слоя извлекаются отдельные числовые надписи. Для каждой сохраняются исходный текст, номер страницы, относительные координаты, тип обозначения и воспроизводимый идентификатор, привязанный к SHA-256 оригинала.
2. Линейные числа отделяются от радиусов, углов, диаметров и составных обозначений. Последние НЕ сопоставляются с габаритами модели автоматически.
3. STEP анализируется настоящим ядром OpenCascade (P8). В P9 дополнительно проверяется список исходных единиц через STEPControl_Reader.FileUnits; измерения сопоставляются только при явно установленных миллиметрах в обоих документах. Для этих трёх чертежей присутствует пометка 尺寸使用毫米 — «размеры в миллиметрах».
4. Пользователь выбирает надпись на чертеже, предполагаемую ось X/Y/Z и окно числового сравнения 0…0,20 мм. Сервер использует Decimal и показывает арифметическую разницу. Выбранное окно НЕ является чертёжным допуском.
5. Результат содержит SHA-256 и ссылки на исходные PDF и STEP, координаты надписи, отметку о неподтверждённости её отношения к общему габариту, редакции и производственного допуска.
6. Доступен исключительно ранее установленный точный набор связей BOM → PDF → STEP. Нечёткие обозначения или другие проекты не допускаются.
7. API: GET /api/engineering/p9/catalog, /annotations?q=..., /compare?q=...&annotation=...&axis=...&window=.... Все маршруты требуют инженерную роль, а сессия и права проверяются повторно перед отправкой ответа.

## Проверка на настоящих документах

- focuser_drawtube: PDF надпись 80 мм, STEP bbox по Y = 80.00086 мм. Абсолютная разница 0.00086 мм.
- lower_square_tube: PDF надпись 437 мм, STEP bbox Y = 437.0 мм, разница 0; также число 35 мм и габарит Z = 35.0 мм, разница 0.
- mirror_cell_base: PDF надпись 24 мм, STEP bbox Y = 24.0 мм.
- Если для 437 выбрать X вместо Y, получится расхождение с X = 220 мм. Система НЕ называет это дефектом детали, потому что нельзя утверждать, что надпись описывает этот габарит.
- R41.5 (радиус) и 67.38° (угол) обнаруживаются, но не могут выступать линейными размерами bbox.

**Существенное ограничение:** одинаковые числа не доказывают идентичность геометрических признаков. P9 НЕ подтверждает размеры отверстий, допуски, сопряжения, геометрию поверхностей, GD&T, актуальную утверждённую редакцию, подлинность штампа или применимость к производственной партии.

## Файлы и зависимости

- dimension_trace.py — связка происхождения P7, результатов P8 и числового сравнения.
- p9_dimension_worker.py — ограниченный PDF-парсер, запущенный в краткоживущем процессе.
- p8_cad_worker.py — расширен извлечением реальных единиц STEP и заданием единицы локальной CAD-системы.
- app.py / app.js / index.html / design-preview.css — API и интерфейс.
- test_dimension_trace.py и p9_browser_harness.py — проверки.

Новая отдельная база не требуется: PDF переанализируется из сверенного оригинала, а STEP берётся из проверенной P8 SQLite. При изменении PDF/STEP кэшированные доказательства не возвращаются.

CAD используется из существующей изолированной среды P8, смонтированной как Windows junction в .p8venv внутри P9. Исходная среда P8 не изменялась. Для независимого развёртывания:

    py -3.13 -m venv .p8venv
    .p8venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements-cad.txt
    python engineering_corpus.py import
    python engineering_inspection.py import

Интерфейс запускается через START_DEMO.cmd и OPEN_DEMO.cmd. Полный набор тестов: TEST_DEMO.cmd. Импорт: IMPORT_CORPUS.cmd.

Среда остаётся демонстрационной: учебные роли без SSO, без PLM/1С и строгой изоляции обработчиков PDF/STEP. Не загружать конфиденциальные производственные архивы.

## Критерии готовности P9

- Доказуемая привязка к 3 реальным комплектам документов через SHA-256.
- Числовое совпадение, расхождение и неопределённость различаются явно.
- Отрицательные случаи (неверная ось, подмена PDF, неизвестные единицы, поддельный ID, отзыв ACL) не дают ложного разрешения.
- Стенды P6/P7/P8 работают отдельно.
- Не утверждается промышленная готовность или соответствие ЕСКД.
